この配信について

0歳の女の子を、みんなのコメントで20歳まで育てる24時間配信です。1時間ごとにコメントの票で「次の1時間にすること」が決まり、作中の1ヶ月は現実の1日で進みます。20歳の誕生日に、オーディションで選ばれた演者の声が初めて入り、VTuberとしてデビューします。大人の視聴者向けの参加型育成企画です。

投票

画面に出ている言葉（例：ミルク、ねんね）をコメントすると票になります。1人1時間1票で、その1時間に最後に書いた言葉が有効です。ひらがな・カタカナ・英語（milk など）でも大丈夫です。節目の投票（名前、部活、髪型など）は「#番号」か選択肢の言葉でコメントしてください。票が1つもない時間は「ねんね」になります。

スパチャ（収益化の承認後に解禁）

スパチャは、チャンネルの収益化が承認されてから解禁します。解禁日は配信とXでお知らせします。解禁後のスパチャは「早く大きくなる」ことと「楽しいこと」にだけ効きます。

  • ¥1,000ごとに作中の時間が1時間ぶん進みます（1日の上限は24時間ぶん、15歳からは12時間ぶん、毎日0時にリセット）。早く進んだぶんは得意なことだけが伸び、性格は変わりません。
  • ¥500でおやつ、¥2,000でプレゼント、¥10,000でおでかけ。行き先は決まった候補の中から、コメントに書かれた場所を選びます。コメント本文は画面に出ません。
  • スパチャで票は増えません。性格・得意なこと・進路は無料の票で決まり、お金では変わりません。
  • スパチャをしなくても、この子が不幸になることはありません。
  • 返金は YouTube の規約に従います。

配信が止まったとき

配信やチャットが止まっている間は、この子の時間も止まります。戻ったら「お昼寝していた」と出ます。

コメントについて

子ども時代が長い配信です。性的・暴力的・差別的なコメント、個人情報、外部リンクの連投は、画面に出さず票にも数えず、場合によってはブロックします。複数アカウントでの投票が疑われるときは運営が確認します。決まった結果は取り消しません。

権利

キャラクター・名前・デザイン・育成の記録の権利は運営に帰属します。

プライバシーポリシー

成長配信の運営（以下「運営」）が、配信と配信アプリで扱う情報についての方針です。

  • 集める情報：配信のライブチャットに投稿されたコメント、投稿者の表示名とチャンネル ID、スーパーチャットの金額と通貨。YouTube Data API を通じて受け取ります。
  • 使い道：票の集計、画面への表示（票を入れた人の名前はテロップに流れます）、荒らしの確認、育成の記録にだけ使います。広告や第三者への提供には使いません。
  • 保存と削除：運営の配信用コンピューターとそのバックアップに保存し、外部には公開しません。デビューの1年後に削除します。
  • YouTube API の利用：配信アプリは、運営自身の YouTube アカウントでログインし、運営のチャンネルのライブ配信とチャットを扱うためだけに YouTube API サービスを使います。視聴者のアカウントにログインを求めることはありません。YouTube の利用には YouTube 利用規約 が、Google によるデータの扱いには Google プライバシーポリシー が適用されます。運営のアプリへのアクセスは Google のセキュリティ設定 から取り消せます。
  • 削除の依頼：自分のコメントの記録を消してほしい場合は、下の問い合わせ先にご連絡ください。

このポリシーを変えるときは、このページを更新し、最終更新日を改めます。
